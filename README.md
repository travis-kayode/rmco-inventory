# RMCO-inventory
A mobile inventory and sales management application designed for a clothing and footwear reseller.

The application replaces an existing spreadsheet-based workflow for locating inventory, recording sales and monitoring monthly performance.

Problem
--- 
RM&CO currently manages clothing and footwear inventory using a spreadsheet. As stock grows, locating items, tracking sales and monitoring inventory becomes increasingly difficult. This project aims to provide a mobile-first system for managing stock, recording sales and viewing business performance.

Requirements
---
- Add new stock to the inventory
- Store brand, item name, colourway, size, condition, location and cost
- View all currently available stock
- Search and filter inventory, particularly by storage location
- Record the sale of an individual item
- Remove sold items from active inventory while retaining their sales history
- View previous sales
- View monthly revenue, costs and profit
